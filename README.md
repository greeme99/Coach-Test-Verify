# KPC 자격인증 서류 사전 검증 시스템 (Coach-Test-Verify)

한국코치협회(KCA)의 KPC(Korea Professional Coach) 자격인증 시험 서류 심사를 대비하여, 작성 완료된 엑셀 서류 3종을 사전에 자동 검증하고 구체적인 수정 조치 가이드를 제공하는 **단독 실행형 무서버 웹 애플리케이션(Single-file SPA)**입니다.

---

## 🚀 주요 특징

1. **완전한 무설치 & 오프라인 100% 구동 (Zero-Server, Zero-Dependencies)**:
   - Node.js나 웹 서버 설치 없이, `index.html` 파일을 더블클릭(`file://`)하는 것만으로 브라우저에서 즉시 작동합니다.
   - SheetJS(`xlsx.full.min.js`) 라이브러리와 SVG 아이콘이 단일 HTML 내에 인라인 번들링되어 **외부 네트워크 요청이 0건**입니다.
2. **철저한 개인정보 보호 (Privacy First)**:
   - 수검자명, 고객명, 코칭 일시, 자격번호 등 모든 민감 데이터는 브라우저 메모리 안에서만 휘발성으로 처리되며, 외부 서버로 일절 전송되지 않습니다.
3. **스마트 자동 분류 & 드래그 앤 드롭**:
   - 3개 서류 파일을 한 번에 화면에 끌어다 놓아도 파일명과 서식 번호(`인증_1_43`, `인증_1_47`, `인증_48`)를 분석하여 해당 슬롯으로 자동 배분합니다.
4. **협회 공식 심사 규정 100% 반영**:
   - **코칭일지**: 총 200시간/유료 40시간 충족 여부, 30~120분 한도, 인원수(`1:n`) 표기, 오류 행 시간 100% 제외, **오류 10건 초과 시 자동 탈락 위험 경고**.
   - **받은 코치더코치**: F열 기재값의 유효성 검증(재가산 없음, 이중 가산 방지), KAC 취득 전 25시간 / 총 80시간 상한 절사.
   - **멘토코칭**: KAC 이후 이수, 이수 기간(일반 60일 / 포트폴리오 90일 이상), 의무 시간(5h / 10h), 단일 세션 60분 초과분 절사, 코치 자격번호 및 '유효' 상태 검증.
   - **1:1 코치더코치**: KAC 이후 1:1 세션, 30~60분 규격, 의무 시간(5h / 8h) 검증.
   - **크로스 타임라인 중복 전수 검사**: 서류 간 상호 이중 기재(Type 1), 코칭과 피코칭 동시 진행 모순(Type 2), 코칭 교육 시간 중 실습(Type 3) 감지.
5. **사용자 편의 기능**:
   - 3종 테마 지원: 라이트, 다크, 그레이-그린 모드.
   - 360px 모바일 화면부터 데스크톱까지 지원하는 반응형 UI (모바일 카드 뷰).
   - 인쇄 친화형 진단 리포트 출력(`@media print`) 및 행별 조치 가이드 마크다운 클립보드 복사.

## 💻 실행 방법

별도의 설치나 빌드 과정 없이, 브라우저에서 `index.html` 파일을 열기만 하면 됩니다:

- Windows 탐색기에서 `index.html` 더블클릭
- 또는 웹 브라우저(Chrome, Edge, Safari 등) 창에 `index.html` 파일을 드래그 앤 드롭

---

## 🧪 테스트 실행

```bash
# 17개 전수 검증 테스트 실행
node tests/run_full_qa.js
```
