## 1. 디자인 철학 및 시스템 토큰

본 시스템은 공문서 검증 도구로서 **신뢰성(Trust), 명확성(Clarity), 가독성(Legibility)**을 최우선 가치로 삼습니다. 외부 CDN 없이 브라우저 내에서 완결되는 순수 CSS 커스텀 속성(CSS Variables) 기반으로 3개 테마를 완벽히 구현합니다.

### 1.1 시스템 폰트 스택
운영체제 기본 서체를 활용하여 외부 웹폰트 다운로드 없이 즉각적인 렌더링을 보장합니다.
```css
font-family: -apple-system, BlinkMacSystemFont, "Pretendard Variable", "Pretendard", "Segoe UI", Roboto, "Helvetica Neue", Arial, sans-serif;
```

- 라이트 모드: 본문 `#0F172A` vs 배경 `#FFFFFF` = **15.8:1** (AA 기준 4.5:1 대폭 초과 만족)
- 다크 모드: 본문 `#F8FAFC` vs 배경 `#1E293B` = **13.4:1** (AA 기준 초과 만족)

## 4. 핵심 UI 컴포넌트 디자인 명세

### 4.1 드래그 앤 드롭 업로드 카드
- 기본 상태: 점선 테두리 (`border: 2px dashed var(--border)`), 모서리 곡률 `border-radius: 12px`.
- 드래그 오버 상태: 실선 테두리 및 은은한 배경 강조 (`border-color: var(--primary)`, `background: rgba(var(--primary), 0.05)`).
- 파일 등록 상태: 단단한 카드 테두리, 좌측에 문서 타입별 고유 뱃지 표시.

### 4.2 종합 스코어보드 카드 (Metric Cards)
- 4열 그리드 레이아웃 (모바일에서는 2열 x 2행 자동 변환).
- 상단에 메트릭 명칭 및 툴팁 아이콘, 중앙에 거대한 수치(`24px Bold`), 하단에 진행 상태 바(Progress Bar) 배치.

### 4.3 오류 태그 및 조치 가이드 툴팁
- `오류 (Error)`: 붉은색 뱃지 (`background: var(--danger-bg); color: var(--danger-text)`).
- `주의 (Warning)`: 노란색 뱃지 (`background: var(--warning-bg); color: var(--warning-text)`).
- `정상 (OK)`: 초록색 뱃지 (`background: var(--success-bg); color: var(--success-text)`).
- 클릭 시 우측에 슬라이드 인 또는 모달 형태로 "엑셀 N행: 120분 초과 -> 조치 방법" 명확한 안내문 노출.

## 5. 인쇄 전용 스타일 명세 (@media print)

사용자가 검증 결과를 종이로 출력하거나 PDF로 저장할 때 용지 여백과 잉크 소비를 최적화합니다.
```css
@media print {
  body {
    background: #FFFFFF !important;
    color: #000000 !important;
    font-size: 11pt;
  }
  /* 불필요한 컨트롤 영역 숨김 */
  header, .theme-toggle, .upload-section, .btn-group, .tab-nav {
    display: none !important;
  }
  /* 리포트 카드 테두리 및 페이지 분할 방지 */
  .report-container, .dashboard-summary {
    box-shadow: none !important;
    border: 1px solid #000000 !important;
    page-break-inside: avoid;
  }
  /* 테이블 출력 최적화 */
  table {
    width: 100% !important;
    border-collapse: collapse !important;
  }
  th, td {
    border: 1px solid #CCCCCC !important;
    padding: 4px 8px !important;
    font-size: 9pt !important;
  }
}
```
