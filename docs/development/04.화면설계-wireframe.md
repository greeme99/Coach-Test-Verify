## 3. 화면별 상태 전이 및 인터랙션 정의

### 3.1 파일 업로드 및 파싱 상태 (Upload States)
- **Empty State**: 파일이 등록되지 않은 초기 상태. 드롭존에 점선 테두리와 "이곳에 3개 엑셀 파일을 끌어다 놓으세요" 안내 문구 노출.
- **Loading State**: 대용량 엑셀 파일 파싱 시 스피너 및 "데이터 정규화 및 검증 엔진 구동 중..." 표시.
- **Success State**: 파일 파싱 완료 시 초록색 체크 아이콘, 파일명, 총 세션 행 수가 슬롯 카드에 표시됨.
- **Error State**: 잘못된 파일 형식이거나 손상된 엑셀일 경우 빨간색 경고 메시지 표시 및 재업로드 유도.

### 3.2 검증 결과 대시보드 상태 (Dashboard States)
- **PASS_EXPECTED State**:
  - 배경: 은은한 에메랄드/그린 계열 배너.
  - 뱃지: "사전 점검: 통과 예상 (PASS)"
  - 안내: "모든 필수 이수 요건을 충족하며 탈락 사유가 감지되지 않았습니다."
- **FAIL_RISK State**:
  - 배경: 은은한 로즈/레드 계열 배너.
  - 뱃지: "사전 점검: 탈락 위험 (FAIL)"
  - 안내: 탈락 위험 사유를 글머리 기호로 요약 표시 (예: "코칭일지 작성 오류 10건 초과 (총 12건 적발)").

## 4. 접근성 및 키보드 조작 설계

- **키보드 탐색**: `Tab` 키로 모든 입력 폼, 파일 선택 버튼, 상세 탭을 순차적으로 이동 가능.
- **포커스 링**: 활성화된 요소에 2px의 뚜렷한 포커스 링(`outline: 2px solid var(--accent)`) 제공.
- **스크린 리더**: 종합 판정 결과 배너에 `role="status"` 및 `aria-live="polite"`를 부여하여 검증 완료 시 즉시 음성 안내.
- **대체 텍스트**: 모든 인라인 SVG 아이콘에 `aria-hidden="true"`를 적용하고, 의미가 필요한 경우 인접한 `span.sr-only` 텍스트로 보완.
