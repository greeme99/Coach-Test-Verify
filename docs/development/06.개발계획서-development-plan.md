## 1. 개발 목표 및 첫 번째 수직 슬라이스 (First Vertical Slice)

### 1.1 최종 인도 목표
설치나 빌드 과정 없이, 브라우저에서 `index.html` 단일 파일을 더블클릭하는 것만으로 오프라인에서 즉시 실행되며, 한국코치협회의 3종 서류를 전수 검증하는 고품질 웹 애플리케이션을 완성합니다.

### 1.2 첫 번째 수직 슬라이스 (Sprint 1 목표)
- **대상 기능**: 코칭일지 단독 업로드 및 기초 검증 파이프라인 관통.
- **범위**: `index.html` 뼈대 구축 -> SheetJS 인라인 번들 로드 -> `1.코칭일지...xlsx` 드롭 시 파싱 -> 필수 열 및 30~120분 한도 검증 -> 오류 행 표시 및 시간 집계 화면 표출.

## 2. 기술 스택 및 아키텍처 전략

### 2.1 스택 선정 기준 및 의존성 고정
- **코어**: 순수 HTML5, Modern Vanilla JavaScript (ES2022+ 클래스 기반).
- **스타일링**: 외부 빌드 도구 없는 순수 CSS (CSS 변수 및 플렉스/그리드 모듈 활용).
- **엑셀 파싱**: SheetJS `xlsx.full.min.js` (v0.18.5 단독 빌드, 약 900KB).
- **인라인 번들링**: SheetJS 스크립트를 `index.html` 내 `<script>` 태그로 직접 인라인 임베딩하여 네트워크 요청 0건을 달성.

## 3. 단계별 개발 로드맵 및 에픽 매핑

| 단계 (Phase) | 중점 작업 내용 | 연계 기능 (FN) | 완료 조건 (DoD) |

## 4. 완료 정의 (Definition of Done - DoD)

1. 모든 소스 코드는 단일 `index.html` 파일 내에 완전 결합되어 로컬 더블클릭으로 즉시 실행되어야 한다.
2. 개발자 도구의 Network 탭에서 일체의 외부 HTTP 요청(CDN, 폰트, 통계 등)이 발생하지 않아야 한다.
3. 협회 예시 파일 및 가상 결함 테스트 데이터 셋에 대해 모든 검증 규칙이 정확히 동작해야 한다.
4. 3개 테마(라이트/다크/그레이-그린) 전환이 원활하며 모바일 화면(360px)에서 가로 스크롤 깨짐이 없어야 한다.
5. 코드 내 미완료 플레이스홀더나 디버깅 로그가 제거되어야 한다.
